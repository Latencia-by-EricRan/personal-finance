# Fonts drop-in

Norte's design brief fixes **Sora** (display/headings) and **Manrope** (body/UI). Neither is
installed on this machine, so OpenPencil can't render them yet.

## What to do

1. Download the `.zip` for each family from Google Fonts:
   - https://fonts.google.com/specimen/Sora
   - https://fonts.google.com/specimen/Manrope
2. Drop the zip **as-is**, unopened, into the matching folder:
   - `Sora.zip` (or whatever name Google Fonts gives it)
   - `Manrope.zip`
3. Tell me it's there — I'll unzip, install the `.ttf`/`.otf` files into `~/Library/Fonts`,
   and re-check `list_available_fonts` in OpenPencil before continuing the design.

Don't unzip or rename manually — just place the file and ping me.
